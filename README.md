# 🌱 Agrimo – Agriculture Website (Frontend Project)

## 📌 Overview
Agrimo is a modern responsive agriculture website built using HTML, Tailwind CSS, and JavaScript.  
It demonstrates real-world frontend UI design with multi-page structure and interactive components.

---

## ✨ Features
- Responsive multi-page layout
- Modern Tailwind CSS design system
- Interactive FAQ accordion (JavaScript)
- Product showcase cards
- Customer testimonial section
- Blog/article layout
- Professional navigation and footer

---

## 🛠️ Technologies Used
- HTML5
- Tailwind CSS
- JavaScript (DOM manipulation)
- Font Awesome
- Google Fonts

---

## 📁 Project Structure
- index.html (Home page)
- about.html (About page)
- faqs.html (FAQ page)
- style.css (Custom styles)
- app.js (JavaScript logic)
- images/ (All assets)
